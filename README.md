## 🔍 Purpose
Security experts use sandboxes to run unknown software safely. A sandbox acts like a cage. It keeps software away from your main computer files. If the software is malicious, it stays inside the cage. 

Sometimes, software finds a way to break out of this cage. This is a sandbox escape. Cagecheck tests your sandbox setup. It checks if your cage holds firm against common breakout attempts. You use this tool to find weak spots in your security.

## 📊 Understanding results
The tool shows the status of your sandbox after the test finishes. 

- Pass: Your sandbox holds the test file. It prevents the software from reaching your main files.
- Fail: The test file escaped the sandbox. Your security settings need attention.
- Warning: The software could not finish the test. This happens if your antivirus software blocks the tool.

If the result shows a failure, check your sandbox software settings. Update your virtualization software to the latest version. Turn on extra security features in your system control panel.

## ❓ Common questions

Does this tool hurt my computer?
No. The tool performs safe tests. It simulates a breakout attempt. It does not change your system files.

What if my antivirus flags this tool?
Security tools sometimes look suspicious to antivirus programs. This is normal. The tool performs actions similar to those used by real exploits. Add an exception for cagecheck in your antivirus settings if you trust the source.

Can I share the results?
Yes. You can save the results as a text file. Use the export button inside the tool window. This is helpful if you work with an IT professional who manages your computer security.
